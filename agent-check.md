
# Дополнительное задание №7. Проверка ИИ-агентом

## Цель
Проверить согласованность диаграммы классов classes.mmd
с диаграммой последовательности из пункта 6.1 методички.

## Правило 1. Сообщение — операция

Проверены вызовы:
- найтиСвободные — СервисБронирования: соответствует.
- получитьЗанятость — Расписание: соответствует.
- свободна — Аудитория: соответствует.
- создатьБронь — СервисБронирования: соответствует.
- пересекаетсяС — Бронь: соответствует.
- сохранить — ХранилищеБроней: соответствует.
- отправить — СервисУведомлений: соответствует.

Расхождений по названиям операций не обнаружено.

## Правило 2. Участник — класс или актёр

Проверены участники:
Сотрудник, СервисБронирования, Расписание,
Аудитория, Бронь, ХранилищеБроней,
СервисУведомлений.

Все семь участников присутствуют в итоговой модели.

## Сравнение с ручной проверкой

До исправления были обнаружены четыре расхождения:
1. isFree вместо свободна.
2. overlaps вместо пересекаетсяС.
3. Отсутствовал класс ХранилищеБроней.
4. Отсутствовал класс СервисУведомлений.

После исправления данные расхождения устранены.

## Вывод

ИИ-проверка подтвердила согласованность названий операций
и состава участников двух моделей. При этом взаимодействия
новых классов ещё необходимо детализировать: соблюдение
двух правил не гарантирует полной корректности архитектуры.
